# Дневник учителя (PWA)

Расписание как в бумажном дневнике: уроки, перемены, дежурства, домашние задания.

## Публикация
1. Залить все файлы в репозиторий GitHub (папку `icons` тоже).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## APK
Откройте https://www.pwabuilder.com, вставьте адрес сайта, нажмите Start → Package for stores → Android.

## Напоминания
В дне нажмите «+ Добавить» → «Напоминание». Уведомления включаются кнопкой «🔔» вверху.
В PWABuilder (Android) включите опцию **Notification delegation**, чтобы разрешение на уведомления работало в APK.

## Контрольные
Под каждым уроком есть выбор «Работа»: контрольная, самостоятельная или проверочная. Метка видна в уроке и в жёлтой плашке сверху («Сегодня» / «Завтра»). Уведомление приходит накануне в 18:00 и утром в 7:00.
